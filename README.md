# Skill Shelf

Skill Shelf is a no-build, dependency-free static showcase of locally used AI agent skills, with data-driven categories, search, expandable descriptions, Chinese/English interface text, and light/dark themes. Metadata is generated by `tools/scan.mjs` → `tools/categorize.mjs` → `data/skills.json`; the site displays only that file’s skill names, descriptions, categories, and recorded sources. To preview locally, run `python3 -m http.server` from this directory and open `http://localhost:8000/`. Deploy the directory as a static site on Vercel without a build command; `vercel.json` enables clean URLs and long-lived CSS/JavaScript caching (one day, with one week of stale-while-revalidate).
