# Skill Shelf

Skill Shelf is a no-build, dependency-free static showcase of locally used AI agent skills, with data-driven categories, search, expandable descriptions, Chinese/English interface text, and light/dark themes. Metadata is generated by `tools/scan.mjs` → `tools/categorize.mjs` → `tools/build-data.mjs` → `data/skills.json` (the inventory files are local and git-ignored); the site displays only that file’s skill names, descriptions, categories, and recorded sources. To preview locally, run `python3 -m http.server` from this directory and open `http://localhost:8000/`. Deploy the directory as a static site on Vercel without a build command; `vercel.json` enables clean URLs and long-lived CSS/JavaScript caching (one day, with one week of stale-while-revalidate).


## Logic circuits

`circuits/<skill>/` holds an audited semantic graph of a skill rendered with the `visualizing-skill-packages` skill: `index.html` (self-contained viewer), `index.graph.json`, `index.coverage.json`, `index.source.md` (the upstream SKILL.md snapshot), `meta.json`, and `LICENSE-upstream.txt`. Circuits are published only for skills whose upstream license permits redistribution, and only after review (`meta.json` `reviewedBy`). `tools/build-data.mjs` links reviewed circuits to their cards. A circuit explains the skill's written workflow; it is not evidence that the skill was run.
